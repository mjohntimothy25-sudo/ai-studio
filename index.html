What is Artificial Intelligence?

Let's break down the core jargon into simple, bite-sized concepts. Hover or click any underlined technical term for instant definitions!

🤖

Artificial Intelligence (AI)

The broad field of computer science focused on building smart machines capable of performing tasks that typically require human intelligence — like recognizing speech, making decisions, or translating languages.

💡 Analogy: If a regular computer program is a fixed recipe, AI is a chef that learns to adjust spices on the fly.
🧠

Machine Learning (ML)

A subset of AI where computers learn patterns from large amounts of training data instead of being explicitly programmed with fixed step-by-step rules.

💡 Analogy: Like showing a child thousands of dog photos until they recognize a dog instantly on their own.
✨

Generative AI (GenAI)

A specialized type of AI model that creates brand-new content — such as essay drafts, realistic images, music, or computer code — based on the patterns it learned from existing human creations.

💡 Analogy: Like an artist who reads millions of books and paints millions of pictures, then creates brand-new original artwork on demand.

Prompt Writing 101

A prompt is your instruction to the AI. Master the 5-part formula to get accurate, high-quality responses every single time.

The Perfect Prompt Formula

👤 Role
+
🎯 Task
+
📖 Context
+
📐 Format
+
⛔ Constraints

1. Role 👤

Assign a persona or field of expertise to set the AI's perspective.

"Act as a senior DevOps engineer..."

2. Task 🎯

Use strong action verbs to state the core goal explicitly.

"Refactor this Python REST API function..."

3. Context 📖

Give relevant background, audience level, or topic boundaries.

"...handling high concurrent database traffic."

4. Format 📐

Define structure: bullet points, 2-column table, code blocks.

"Provide optimized code with line comments."

5. Constraints ⛔

Set strict rules: length limits, tone requirements, things to avoid.

"Use async/await. Avoid external third-party libs."

Bad Prompt vs. Good Prompt Comparisons

❌ Vague Prompt

"Write a essay on climate change."

Why it fails: No length specified, no target audience, generic tone, high risk of fluffy or irrelevant response.
VS
✅ Master Prompt

"[Role] Act as an environmental science professor. [Task] Write an introductory summary on climate change impacts on ocean reefs. [Context] Target high school students. [Format] Use 3 clear paragraphs with a summary bullet list. [Constraints] Max 250 words, friendly tone."

Why it wins: Direct, focused, structured output tailored to the exact audience.

Ethics & Digital Citizenship

Responsible AI Use for Developers & Students

AI is a powerful thought partner, not a replacement for your original thinking or code security audits.

✅ DO (Best Practices)

  • Use AI for brainstorming: Generate outline ideas, alternative code refactoring angles, or study questions.
  • Fact-check everything: Verify claims, statistics, and API syntax against official documentation.
  • Learn concepts step-by-step: Ask AI to explain complex system designs or debugging error logs.
  • Cite AI transparently: Follow school and repository open-source guidelines when AI assists your work.
  • Protect your privacy: Never submit private API keys, user passwords, or confidential corporate secrets into public AI chats.

❌ DON'T (Pitfalls to Avoid)

  • Don't copy-paste code blindly: Unchecked AI code can contain critical security vulnerabilities or deprecated functions.
  • Don't trust AI blindly: Models can hallucinate fake library package names or non-existent API parameters.
  • Don't bypass learning: Relying solely on AI to solve coding assignments prevents deep algorithmic thinking.
  • Don't upload proprietary secrets: Keep confidential production code out of unvetted AI models.
  • Don't ignore license terms: Verify open-source software license compatibility when consuming AI snippets.

📚 How to Cite AI in Academic & Software Work

When permitted by your instructor or organization, cite AI interactions properly:

MLA Style: OpenAI. "ChatGPT response to query regarding photosynthesis." ChatGPT, 15 Sep. 2026, chatgpt.com.
Code Comment Citation: # Code generated with assistance from GitHub Copilot (GPT-4o) on 2026-10-01. Reviewed and tested manually.
